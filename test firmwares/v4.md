# v4 — accelerometer noise filtering

Adds a symmetric 40 Hz first-order accelerometer low-pass, using actual elapsed sample time. Gravity and sustained acceleration retain unity gain. Gyro filtering remains 80 Hz; USB readiness pacing is unchanged. Accelerometer response gains approximately a 4 ms time constant, a deliberate noise/latency tradeoff.

SDL Controller Test's noise profiling restarts when the sample-to-sample acceleration vector difference exceeds 0.075 g. Its noise evaluation requires 4.5 seconds without such a reset, followed by five seconds of drift evaluation. High-frequency acceleration noise or alternating offsets from independent sensor samples can trip this gate. v4 attenuates these changes; physical confirmation is still required. Sustained vibration or actual motion should still invalidate calibration.

Flash the v4 UF2, leave the unit untouched on a firm surface, wait for firmware startup calibration, then initiate SDL calibration and leave it untouched for at least ten seconds. If the noise phase still resets, capture the numerical acceleration readings or run tools/check_motion.py separately. Do not zero gravity to force calibration to pass.

Validation: host gyro/DS4/IMU suites pass; added accelerometer test verifies attenuation of synthetic alternating 0.1 g steps, preserved 1 g gravity and correct sustained tilted output. RP2040 compile and UF2 checks pass. Physical SDL noise calibration remains unverified.
