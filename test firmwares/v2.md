# v2 — gyro calibration lockout correction

Flash DGB_ICM45686_calibration_DS4_1kHz_TEST_v2.uf2 using BOOT mode, then leave the device stationary for startup calibration.

v1 could permanently report zero gyro when its stationary calibration failed or timed out. v2 removes that output gate: valid sensor motion is reported during calibration and after a failure. The driver uses zero bias until its first successful calibration, or retains the previous good bias during later attempts. A failed calibration can therefore leave drift, but cannot by itself disable gyro output. The old UF2 is preserved as v1; future changed binaries receive increasing version suffixes.

Open USB serial at 115200 and send `?` to inspect IMU status, calibration status and fresh sample count. Send `c` while fully stationary to retry calibration. If motion is still absent, include the `?` response, whether JoyShockMapper detects the controller, and whether fresh sample counts increase between queries. This distinguishes a missing sensor stream from a host/report problem.
